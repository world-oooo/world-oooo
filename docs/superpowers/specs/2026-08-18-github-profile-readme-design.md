작성일: 2026-08-18
대상 계정: [`World525`](https://github.com/World525) (표기 주의 — 대문자 `W`)

## 1. 배경과 목적

사용자가 Instagram [@gitskins](https://www.instagram.com/gitskins) 계정의 화려한 GitHub 프로필 영상을 보고 동일한 수준의 프로필을 원함.

리서치 결과, 해당 영상들의 프로필은 특별한 기술이 아니라 **외부 서비스가 실시간 생성하는 SVG를 마크다운 이미지로 삽입한 것**이었다. 재현 난이도는 낮으나, 서비스 가용성과 GitHub의 HTML 필터링이라는 두 가지 실질적 제약이 존재한다.

**목적**: 개인 기록/취미용 프로필. 취업·채용 목적 아님. 따라서 경력 어필보다 개성과 분위기를 우선한다.

작업 폴더 `github꾸미기/`를 그대로 git 저장소로 사용하고, 원격 저장소 `World525/World525`에 push한다.

### 5.1 terminal.svg 사양

**자체 제작하는 이유**: GitHub은 README의 HTML을 필터링하며 `style` 속성과 `<style>` 태그를 제거한다. 허용 속성은 `href, src, title, alt, width, height, align, target, lang` 등으로 제한된다. 따라서 터미널 창(테두리·타이틀바·신호등 점)을 HTML/CSS로 구현할 수 없다. 반면 **저장소에 커밋한 SVG 파일은 내부 애니메이션을 포함한 채 상대경로로 렌더링된다.**

- **캔버스**: `viewBox="0 0 760 212"`
- **애니메이션 방식**: **SMIL만 사용** (`<animate>`). CSS·JavaScript 미사용 — 필터링을 확실히 통과시키기 위함
- **주기**: 8초 무한 반복
- **폰트**: `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace` (시스템 폰트만. 웹폰트는 로드되지 않음)
- **구성**: 라운드 사각형 창(`#010409`, 테두리 `#30363d`) + 타이틀바(`#161b22`) + 신호등 3점 + 타이틀 `world525@github: ~`

**타임라인**

| 시점 | 내용 | 색 | 기법 |
|---|---|---|---|
| 0.0–0.8s | `$ whoami` 타이핑 | `$`=그린, 명령=`#e6edf3` | clipPath 폭 애니메이션 |
| 1.2s | `World525` 출력 | `#A855F7` | opacity |
| 1.8–3.2s | `$ cat status.txt` 타이핑 | 동일 | clipPath 폭 애니메이션 |
| 3.6s | `still learning. still building.` | `#8b949e` | opacity |
| 4.4s~ | `$` + 커서 블록 깜빡임 | 커서=`#00F0FF` | opacity, 1.1초 주기 |
| 8.0s | 리셋 후 반복 | — | `repeatCount="indefinite"` |

타이핑 효과는 **텍스트 위에 clipPath 사각형의 `width`를 0에서 전체 폭까지 애니메이션**하여 좌→우로 드러내는 방식으로 구현한다.

## 6. 외부 서비스 실측 (2026-08-18)

`curl`로 직접 확인한 HTTP 응답 코드:

| 서비스 | 코드 | 판정 |
|---|---|---|
| capsule-render | `200` | 채택 |
| shields.io | `200` | 채택 |
| komarev (방문자) | `200` | 채택 |
| streak-stats.demolab.com | `200` | 주석 보관용으로 유효 |
| **github-readme-stats** | **`503`** | **현재 장애** |
| **github-profile-trophy** | **`402`** | **Payment Required — 무료 인스턴스 사실상 중단** |

`github-readme-stats`의 `503`은 알려진 고질적 문제다. 공용 인스턴스가 GitHub API 시간당 5,000회 한도를 전체 사용자와 공유하기 때문에 과부하 시 응답이 실패한다 ([이슈 #3226](https://github.com/anuraghazra/github-readme-stats/issues/3226) 외 다수). `github-profile-trophy`의 `402`는 Vercel 요금 문제로, 서비스 측 조치 없이는 복구되지 않는다.

**이 실측 결과가 §2의 "통계 위젯 제외" 결정을 사후적으로 뒷받침한다.** 저장소가 0개라 숫자가 0으로 나오는 문제 이전에, 서비스가 응답하지 않아 **깨진 이미지 아이콘**이 표시되었을 상황이었다.

## 7. 통계 위젯 주석 블록

README 하단에 아래 형태로 **완성된 코드를 주석 안에 보관**한다. 공개 저장소가 생겼을 때 주석 기호 두 줄(`<!--`, `-->`)만 삭제하면 즉시 활성화된다.

포함 대상:
1. 커밋 통계 카드 (`github-readme-stats`)
2. 언어 비율 (`top-langs`)
3. 연속 커밋 스트릭 (`streak-stats.demolab.com` — herokuapp 구 도메인 아님)

**트로피는 포함하지 않는다.** `402` 응답으로 서비스가 중단된 상태이며, 복구 시점을 알 수 없어 주석으로 남겨도 오작동 코드를 방치하는 셈이 되기 때문이다. 주석 안에 트로피가 제외된 사유를 한 줄로 명시한다.

주석 블록 첫 줄에 활성화 방법과 §6의 서비스 불안정성 경고를 함께 적는다.

## 8. 검증 방법

구현 완료의 판정 기준:

1. **파일 존재**: `README.md`, `assets/terminal.svg`, `.gitignore` 생성 확인
2. **SVG 유효성**: `terminal.svg`를 XML 파서로 파싱하여 오류 없음 확인
3. **SVG 애니메이션**: 브라우저에서 열어 8초 주기 4단계(타이핑→출력→타이핑→커서)가 모두 재생되는지 육안 확인
4. **외부 URL 생존**: README에 포함된 모든 외부 이미지 URL에 `curl`로 요청하여 전원 `200` 확인
5. **금지 요소 부재**: `README.md`에 `style=` 속성과 `<style>` 태그가 존재하지 않음을 grep으로 확인 (GitHub이 제거하므로 있으면 설계 위반)
6. **상대경로 정확성**: README의 SVG 참조 경로가 `assets/terminal.svg`와 정확히 일치
7. **git 상태**: 커밋 완료, `.superpowers/`가 추적되지 않음

**push는 사용자가 직접 수행한다.** 원격 저장소 `World525/World525` 생성과 push 명령을 안내하되, 에이전트가 대신 실행하지 않는다.
